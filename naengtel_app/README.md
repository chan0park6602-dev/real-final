# 러닝페어 4조 — 보유 식재료 기반 레시피 추천 프로그램

자취생 냉장고·냉동실에 쟁여 둔 **간편식과 냉동식품**(컵라면, 3분카레, 냉동볶음밥, 떡갈비 등)에 남은 재료만 더해 그럴듯한 한 끼를 만들 수 있도록 돕는 프로그램입니다.
가진 식재료를 입력하면, 직접 만든 레시피 데이터(841개)와 비교해
**추가로 살 재료가 적고 비용이 싼 메뉴부터** 추천하고, 부족한 재료를 장보기 목록으로 모아 주는 Streamlit 앱입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 자동으로 열리며, 첫 화면은 바로 '내 냉장고(재고 관리)'입니다.
노트북·데스크톱 화면(가로 1280px 이상)에 맞춰 왼쪽 고정 메뉴 + 넓은 작업 영역으로 구성했습니다.
(필요 버전: Python 3.9 이상, Streamlit 1.39 이상)

## 파일 구성

```
app.py                 실행 파일 (첫 화면으로 바로 이동)
core.py                핵심 로직 — 데이터 불러오기, 재료 비교, 추천 정렬, 검색, 장보기 목록
common.py              모든 화면이 함께 쓰는 부분 — 사용자 상태, 디자인, 왼쪽 메뉴, 레시피 카드·상세
pages/                 (서버 환경에서 경로 오류가 없도록 파일 이름은 영어로 둠)
  1_fridge.py          분류별 탭에서 재료를 눌러 담기·빼기, 기본 재료 설정
  2_recommend.py       부족 재료 수·추가 비용 순 추천 (0개 / 1개 / 2개 / 3개 이상 구역)
  3_search.py          메뉴 검색 → 필요·보유·부족 재료 비교, 대체 재료, 조리법
  4_cart.py            선택한 메뉴의 부족 재료 통합(중복 제거), 예상 비용 합산
data/
  ingredients.csv      식재료 263개 (분류, 대표 가격, 기본 재료 여부)
  recipes.csv          레시피 841개 (분류, 재료, 조리법 — 재료·단계는 '|'로 구분)
  substitutes.csv      대체 식재료 248쌍 (사용 가능 요리, 주의점)
images/logo.png        로고 (음식 사진은 images/R001.jpg처럼 넣으면 카드에 자동 표시)
static/                G마켓 산스 폰트
.streamlit/config.toml 화면 설정 — Streamlit Cloud에 올릴 때는 저장소 맨 바깥에도 같은 .streamlit/config.toml을 둬야 적용됨. (기본 메뉴 숨김, 폰트 경로 허용, 색상)
```

## 핵심 함수 (core.py)

| 함수 | 하는 일 |
|---|---|
| `load_ingredients()` / `load_recipes()` / `load_substitutes()` | CSV 데이터 불러오기 |
| `compare_ingredients()` | 레시피 재료와 내 재고를 비교해 보유·부족 재료로 나눔 |
| `find_missing_ingredients()` | 부족 재료 = 필요한 재료 − 현재 재고 |
| `calculate_extra_cost()` | 부족 재료의 대표 가격 합산 |
| `recommend_recipes()` | 1순위 부족 재료 수, 2순위 추가 비용 순으로 정렬 |
| `search_recipe()` | 메뉴 이름(공백 무시)·재료 이름으로 검색 |
| `find_substitutes()` | 부족 재료의 대체 식재료 찾기 |
| `create_shopping_list()` | 선택한 메뉴들의 부족 재료를 중복 없이 통합 |

## 참고

- 추천 화면의 '🍱 간편식 활용' 필터는 간편식·냉동식품이 들어간 레시피만 모아 보여 줍니다.
- 가격은 실시간 판매가가 아닌 팀에서 정한 대표 가격입니다.
- 소금·설탕·간장·식용유·후추는 '기본 재료'로, 체크해 두면 늘 있는 것으로 계산합니다.
- 처음 접속하면 냉장고와 장보기 목록은 비어 있는 상태로 시작하며, 입력한 내용은 그 접속(브라우저 탭) 동안 유지됩니다.
